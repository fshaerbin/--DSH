# 陈墨 · Mori Chen — 科技风个人网站

一个使用**模拟数据**搭建的科技风个人网站，深色霓虹配色、粒子背景、终端开场、响应式布局，纯静态实现（HTML + CSS + JavaScript，无构建依赖）。

## 在线预览

直接打开 [`index.html`](index.html)，或用任意静态服务器本地运行：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 结构

```
index.html       页面结构（Hero / 关于 / 技能 / 项目 / 经历 / 联系）
css/style.css    样式（深色主题、霓虹配色、响应式、动画）
js/main.js       交互（粒子背景、打字机、数字滚动、滚动进场、移动端导航）
docs/screenshots 截图预览
```

> 说明：站内所有人物、项目、经历与联系信息均为**模拟数据**，仅用于演示。
